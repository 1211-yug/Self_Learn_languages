# 🧮 Simple Calculator

A clean, responsive calculator web app built with **HTML, CSS, and JavaScript** — featuring a smooth animated gradient background and a Dark Mode / Light Mode toggle.

🔗 **Live Demo:** [https://simple-calculator-4.netlify.app/]

## ✨ Features

- ➕ Basic arithmetic operations: addition, subtraction, multiplication, division, and percentage
- 🌗 Dark Mode / Light Mode toggle with animated gradient backgrounds
- ⌫ Delete last digit (DEL) and clear all (AC) functionality
- 📱 Responsive, minimal UI with smooth hover effects
- 🎨 Custom CSS animations for background transitions

---

## 🛠️ Tech Stack

- **HTML5**
- **CSS3**
- **JavaScript** 

---

## 📂 Project Structure

```
├── index.html      # Markup and layout
├── style.css       # Styling and animations
├── script.js       # Calculator logic and theme toggle
```
