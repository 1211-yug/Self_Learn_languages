# 📷 Instax Mini 12 - Product Landing Page

A modern and responsive product landing page inspired by the Instax Mini 12 instant camera.

This project was created to practice HTML, CSS, responsive web design, UI design, and interactive CSS components.

## 🚀 Live Demo

🔗 

## ✨ Features

- Modern and clean landing page
- Responsive design
- 4 product colour variants
- Interactive product colour slider
- Previous / Next navigation
- Product pricing section
- Product variants section
- Camera features section
- Product gallery section
- Smooth scrolling navigation
- Call-to-action buttons
- Responsive mobile layout

## 🎨 Available Colours

- Pastel Blue
- Pastel Green
- Pastel Pink
- Pastel Lilac

## 🛠️ Technologies Used

- HTML5
- CSS3
- Font Awesome
- Google Fonts
