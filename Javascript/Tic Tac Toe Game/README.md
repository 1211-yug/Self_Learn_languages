# 🎮 Tic-Tac-Toe Game

A simple, classic Tic-Tac-Toe (Noughts and Crosses) game built with **HTML, CSS, and JavaScript**. Play the traditional 2-player game right in your browser — no frameworks, no dependencies, just clean front-end fundamentals.

## ✨ Features

- Two-player gameplay (Player O vs Player X)
- Automatic winner detection across all 8 possible winning combinations
- Draw detection when the board fills up with no winner
- "New Game" and "Reset Game" options
- Clean, responsive UI that adapts to mobile screens

## 🛠️ Built With

- **HTML5** – structure
- **CSS3** – styling, layout (CSS Grid, Flexbox), and responsiveness
- **JavaScript (Vanilla)** – game logic, DOM manipulation, event handling

## 📂 Project Structure

```
├── index.html      # Markup for the game board and modal
├── style.css       # Styling and responsive layout
├── script.js        # Game logic and event handling
```

## 🎯 How to Play

1. The game starts with Player **O**.
2. Click any empty box on the grid to place your mark.
3. Players alternate turns between **O** and **X**.
4. The first player to align 3 of their marks (horizontally, vertically, or diagonally) wins.
5. If all 9 boxes are filled with no winner, the game ends in a draw.
6. Click **New Game** or **Reset Game** to play again.
