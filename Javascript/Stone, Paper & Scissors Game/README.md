# 🎮 Rock Paper Scissors Game

A simple and interactive **Rock Paper Scissors Game** built using **HTML, CSS, and JavaScript**.

The player can choose Rock, Paper, or Scissors, while the computer randomly generates its choice. The game then compares both choices and displays the result along with the updated score.

## ⚙️ How It Works

1. The user selects **Rock, Paper, or Scissors**.
2. JavaScript generates a random computer choice.
3. The selected choices are displayed on the screen.
4. The game compares the user's choice with the computer's choice.
5. The winner is determined.
6. The score is updated.
7. A message displays whether the user won, lost, or the game was a draw.
